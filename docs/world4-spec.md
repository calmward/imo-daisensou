# World 4「ゆきの くに」仕様（デザイン担当セッションとの相談結果）

あらすじ: イモクイ大王をたおしたら、兄の「こおり大王」が いもばたけを こおらせに きた。

## 新メカニクス（3つ）
1. **split {id, n}**: 倒れると id を n 体（x, x+28）に分裂。親の強さ（mult）を引きつぐ。上限を無視。「パカッ！」。HP50%以下でヒビ。
2. **revive {frac}**: はじめて HP0 になったとき 2秒 こおりのかたまり（攻撃・ビーム無効）→ maxHp×frac で復活（「ふっかつ！」）。
   `strongVs` に 'ice' をもつ仲間がトドメなら復活しない（「とけた！」）。復活前は「1」バッジ。
3. **skills [{every?, below?, kind, id?, n?}]**: stomp（450以内の味方をふっとばす）/ summon（id を n体、親mult/1.7、最大4体）/ blizzard（8秒 むかいかぜ）。

## ステージ付加要素 StageDef.mod
- **blizzard ふぶき**: 30秒から35秒ごと7秒の突風。3秒前に「ふぶきが くるよ！」。むかいかぜ（いも×0.5・てき×1.4）と おいかぜ（逆）を交互。歩く速さだけ。
- **slippery つるつる**: ふっとび距離×1.7、歩く速さ+15%。「つるーん！」。
- **festival ゆきまつり**: てきの おかね×2。
